접힌 몸 / FOLD - WebAR

작품 흐름
십자가 형태로 펼쳐진 예수의 이미지를 인쇄하고 접으면, 몸의 각 부분이 큐브 안으로 모입니다. 웹 화면에서는 같은 면을 경첩처럼 접는 애니메이션을 재생합니다.
이 버전은 인체의 무릎·허리 관절을 움직이는 캐릭터 애니메이션이 아니라, 이미지가 입혀진 큐브의 접힘으로 웅크림을 표현합니다.

1. 인쇄와 조립
cube_net_A4.pdf를 A4, 실제 크기 100%로 인쇄합니다. 페이지 맞춤은 끕니다.
한 면은 48 x 48 mm, 완성 큐브도 한 변 48 mm입니다.
바깥 실선을 따라 풀칠 탭을 포함해 자릅니다. 여섯 면의 경계와 탭의 뿌리를 접습니다.
그림이 바깥을 향하도록 양옆·위·아래 면을 접고, 가장 긴 끝 면을 닫습니다. 탭은 안쪽에 붙입니다.
무광 용지를 권장합니다. 하단 48 mm 검증선을 자로 재면 출력 배율을 확인할 수 있습니다.

2. 웹 실행
압축을 풀어 index.html, assets 폴더, PDF를 같은 구조로 HTTPS 웹호스팅에 올립니다.
휴대폰에서 HTTPS 주소를 열고 카메라 AR을 누른 뒤 카메라 사용을 허용합니다.
HTML을 파일 앱에서 직접 여는 방식은 지원하지 않습니다.
PC 미리보기: 해당 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000 접속.
휴대폰에서 PC의 http://내부IP 주소로 접속하면 카메라 보안 제한이 있을 수 있으므로 HTTPS 배포를 사용합니다.
Three.js와 MindAR를 CDN에서 불러오므로 인터넷이 필요합니다.

3. 조작
접기·재생: 약 4.5초에 걸쳐 전개도를 큐브로 접습니다. 다시 누르면 일시정지합니다.
펼치기: 초기 전개도로 돌아갑니다.
슬라이더: 접힘 정도를 직접 조절합니다.
3D 화면: 드래그 회전, 스크롤 또는 핀치 확대.
AR 화면: 인쇄한 전개도 전체 또는 큐브의 얼굴·상체 면(전개도 중앙)을 비춥니다.
조립된 큐브에서는 해당 면이 카메라를 향해야 합니다. 완전한 3D 물체 인식이나 모든 면의 연속 추적은 아닙니다.
자동 재생이 아니라 접기 버튼으로 재생하므로 설치 현장에서 원하는 순간에 시작할 수 있습니다.

4. 제공 자료
index.html: WebAR와 3D 미리보기.
cube_net_A4.pdf: 풀칠 탭이 포함된 인쇄용 전개도.
assets/targets.mind: 전개도 전체, 중앙 얼굴·상체 면 순서로 컴파일된 인식 데이터.
assets/net-target.jpg: 전개도 전체 인식 원본.
assets/center.png 등: 각 면의 이미지.
assets/CubeA.glb, CubeB.glb: 제공받은 원본 모델.

제작 기준과 한계
CubeA의 원본 UV 매핑에서 여섯 면의 이미지를 추출했습니다. 따라서 상단 명패 면의 늘어난 비율 등 원본 매핑의 왜곡도 유지됩니다.
CubeB는 면의 크기가 서로 달라 종이로 정육면체를 닫기 위해 정사각형 여섯 면으로 정규화했습니다.
화면의 접힘은 CubeA의 면 이미지를 입힌 별도 경첩 구조입니다. GLB 원본은 변경하지 않았습니다.
AR 대상 데이터를 사전 생성하고 파일·구조·접힘 좌표를 검사했습니다. 실제 휴대폰 카메라와 종이 인식 품질은 현장 검증이 필요합니다.
너무 가까이 들이대거나 반사광이 비치거나 상체 면이 가려지면 인식이 끊길 수 있습니다.
